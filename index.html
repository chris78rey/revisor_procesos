Ordenar texto o reporte con IA

Pega el contenido como lo recibiste: tabla, correo, oficio, lista o texto mezclado. La IA intentará ordenar los datos del proceso y separar cada novedad; podrás revisar y corregir la propuesta antes de guardarla. Si conoces el chat ID de Telegram del responsable, inclúyelo junto a su nombre así: Juan Pérez [Telegram ID: 123456789]. El ID se guardará con el responsable; si no lo tienes, basta con ingresar su nombre.

Se extraerá el texto para proponer datos y se enviará a OpenRouter al pulsar Ordenar texto. El archivo original no se guarda con este análisis; después de crear el expediente, adjúntalo en Documentos. Máximo 25 MB; OCR de PDF escaneado hasta 40 páginas y 100 KB de texto extraído.
